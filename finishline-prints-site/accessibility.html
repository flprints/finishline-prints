Accessibility Statement

Last updated: November 2026

Our aim

Finishline Prints wants everyone to be able to read this website and contact us. We build pages so they can be used with a keyboard, a screen reader and on small screens.

What we have done

  • Headings, lists and landmarks are used so assistive technology can move around the page.
  • A “Skip to content” link is at the top of each page, and links and buttons can be reached with the keyboard.
  • Images carry text descriptions, and decorative graphics are hidden from screen readers.
  • Animations are switched off for people who ask their device for reduced motion.
  • The layout adapts to phones, tablets and desktops.

Limits

This website has not yet been through a formal accessibility audit, so some parts may not work well for everyone.

Tell us if something does not work

If you have trouble using this website, call us on +91 99448 83927 or write to finishlineprint@gmail.com. We will help you directly and use your feedback to improve the site.
